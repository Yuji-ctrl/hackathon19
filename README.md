# Unity-Based Food Game Project

## Project Overview
This project is a fun and interactive food-themed game developed in Unity. Players can explore various levels, collect food items, and overcome obstacles while learning about nutrition and healthy eating.

## Features
- **Engaging Gameplay**: Explore levels filled with food items and challenges.
- **Educational Content**: Learn about nutrition as players collect food items.
- **Multiple Levels**: Various levels with increasing difficulty.
- **Customizable Characters**: Players can choose and customize their characters.
- **Sound Effects and Music**: Enjoy an immersive experience with sound effects and background music.

## Installation Instructions
1. **Clone the Repository**: 
   ```bash
   git clone https://github.com/Yuji-ctrl/hackathon19.git
   ```
2. **Open the Project in Unity**:  
   Open Unity Hub and add the cloned project folder.
3. **Install Required Packages**:  
   Ensure you have the necessary Unity packages installed, which can be found in the `Packages/manifest.json` file. You can do this by navigating to the Package Manager in Unity.
4. **Build and Run**:  
   Click on "Build and Run" from the File menu to test the game.

## Usage Examples
- **Starting the Game**: Launch the game from Unity or the built executable.
- **Collect Food Items**: Move your character to collect food items scattered throughout the levels.
- **Complete Levels**: Successfully navigate through challenges to complete each level.
- **Access Settings**: Customize your gameplay experience in the settings menu.
